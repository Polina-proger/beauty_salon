## Общий стиль картинок
- Палитра: бордо, светлый бело-бежевый, теплый коричневый.
- Допустимый редкий акцент: холодный темно-зеленый.
- Настроение: quiet luxury, editorial, premium beauty, soft shadows.
- Лучше без кричащих цветов, без ярко-розового и без кислотных оттенков.
- Вес одного файла лучше держать примерно `180–450 KB`.
